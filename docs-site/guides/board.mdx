## Keep the work in view

Structure is the saved design. Drag agents, groups, and the Input block to arrange them. Keyboard controls are available for movement and inspection. Stop the team before editing its components and arrows.

Use the project name control to rename it. The workspace menu opens Projects, Library, Community, and panel controls; there is no permanent dashboard toolbar above the board.

## Connect work

Connections describe intended handoffs. Workflow routes can branch on outcomes or return work for another review. A planned arrow does not prove that a message was sent; inspect Live or Communications for observed activity.

## Reuse groups

Create a group independently in the private Library, save it, and insert it into any project. Collapsing a group hides its internal blocks and arrows while preserving its color and external connections.

Imported groups still need review. Check the jobs, folder, permissions, entry points, and completion routes before starting.

<Warning>A stage with no route to completion blocks startup. Connect its intended outcome, or remove it from the workflow if it is not part of the design.</Warning>

## Input and Text Mode

Input accepts links, rough thoughts, instructions, and source notes. Move it like any other board component.

Text Mode expands the **whole conversation**, including its transcript and composer. Use Exit Text Mode to return to the board. It is not just an enlarged message field.
