# Sculptured artwork

`sculptured-coastal-emblem.png` is the original artwork supplied by the project owner
as `~/Downloads/Sculptured Coastal Emblem.png`. The image is preserved unchanged.
Compact application marks frame its coastal symbol with CSS; the original wordmark
remains in the source asset. The browser icon uses the complete artwork.

The application palette is defined in `web/src/coastal.css`. It retains separate
status and agent-provider colors, as well as the existing text and shape indicators.
